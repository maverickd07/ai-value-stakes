# Prospective stakes-v5 allocation

This is the actual fixed allocation of 432 newly admitted Qwen histories: 108 per arm and 18 per wording/option-order stratum. The bank passed the registered screening before assignment. The deposit was made after admission and before any main decision. Only experimental IDs and design assignments are included; no notes, outputs, credentials or private account records. The original design and implementation releases remain separate historical versions.
